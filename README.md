# 经纪人模拟器：塌房危机 🌟

> 你是一名娱乐经纪人。你的艺人每天都在塌房的边缘疯狂试探。你能撑过20天吗？

## 在线体验

**👉 [savemystar.pages.dev](https://savemystar.pages.dev)**

## 简介

一款模拟娱乐圈经纪人日常的文字策略游戏。你需要在商业价值、粉丝忠诚度和舆论风险之间艰难平衡，应对各种突发事件——品牌方暴怒来电、AI换脸丑闻、粉丝内战、艺人深夜崩溃……每个选择都有代价，每天都是新的危机。

## 特色

- 4 位性格迥异的艺人可选（流量偶像 / 实力演员 / 唱跳歌手 / 网红转型）
- 80+ 精心设计的事件，每个选项都没有"正确答案"
- 紧急来电系统：全屏来电界面，接听或挂断都有后果
- 10 种结局：从顶流巅峰到全网封杀
- 竞争对手系统、公司升级、微博发帖、整容系统等丰富玩法
- 纯前端，无需后端，移动端优先的响应式设计

## 技术栈

- Next.js 14 (App Router, Static Export)
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand

## 本地开发

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可体验。

## 部署

项目通过 Cloudflare Pages 部署，推送到 main 分支后自动构建发布。
