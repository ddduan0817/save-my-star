# 微博配图生成清单

## 统一要求

- 所有图片以对应 `public/artists/*.png` 作为人物参考，必须保持脸型、发色、发型和整体气质一致。
- 风格使用精致二次元半写实游戏插画，但画面要像艺人本人或工作室用手机/相机拍下的真实微博配图，不要做成宣传立绘。
- 建议尺寸：横版 4:3，1200 × 900；主体保留在中央 70% 安全区，方便移动端裁切。
- 不要生成文字、Logo、水印、微博界面、边框、拼图模板或品牌商标。
- 不要改变角色性别，不要增加未说明的亲密人物，不要使用夸张舞台特效遮挡主体。
- 文件使用 WebP 或 PNG，按下列建议文件名提供。

- 公益：需要先确定具体公益项目，避免做成空泛摆拍。
- 深夜感悟：现有纯文字表达已经成立，可等核心 25 张完成后再补。
- 机场路透和站姐版权图：需要先确定是否复用工作照素材并叠加前端水印，不建议重复生成相似人物图。
