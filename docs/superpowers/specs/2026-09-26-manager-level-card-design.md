# 工作台经纪人等级卡恢复设计

## 目标

恢复已从旧“我的”页面移除的经纪人等级展示，并将其放在工作台最顶部、“舆情雷达”上方。

## 组件边界

新增独立组件 `src/components/game/features/ManagerLevelCard.tsx`，只负责读取并展示：

- 当前经纪人称号与等级
- 当前 XP 和下一级所需 XP
- 当前等级进度条
- 距离下一级所需经验
- 最近三天 XP 净值为负时的状态滑坡提示
- 达到异常条件时的特殊称号

等级、经验和特殊称号仍由 `src/engine/managerProgression.ts` 计算。组件不复制等级阈值，也不修改 XP 结算逻辑。

## 页面位置

`WorkspaceTab` 的顺序调整为：

1. 经纪人等级卡
2. 舆情雷达
3. 概览 / 大粉 / 保险切换
4. 当前子页面内容

等级卡始终显示，不受工作台内部子页面切换影响。

## 显示规则

- 普通状态：显示称号、`Lv.N`、经验值、进度条、升级差值和当前天数。
- 满级状态：显示 `MAX`，并提示已达最高等级。
- 状态滑坡：最近三天 XP 净值小于 0 时显示警告。
- 特殊称号：满足特殊状态时突出显示特殊称号，同时保留原等级信息。
- 无艺人数据时使用中性兜底，不显示 `undefined`。

## 验证

- 新局工作台顶部显示 `实习经纪人 Lv.1`。
- XP 变化后进度条和差值同步更新。
- 升级后称号和等级即时更新。
- 特殊称号优先显示，原等级仍可见。
- 工作台切换“概览 / 大粉 / 保险”后等级卡保持可见。
- 移动端不与顶部状态栏、舆情雷达或底部导航重叠。
